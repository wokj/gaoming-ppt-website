37 城分舵复制蓝图（L4 长期复制出口 · 2026-08-05）

定位：门派网络复制 = 亿级两腿之一（v3 甲：门派网络），对标 waytoAGI「AI 切磋大会」37 城蔓延 前提：门派基座跑通且月活达标才放分舵——分舵是结果，不是起点 单分舵模型：认证讲师（分舵长）+ 本地渠道（夜校/高校/政企）+ 本地社群（研习社城市版） 对齐：认证体系（Lv1-Lv3）、切磋大会、作业飞轮

一、为什么是分舵（亿级出口）

  • v3 诚实测算：垂直教学 IP 天花板 ≈ 数千万（旁门左道量级）。要破亿必须长第二条腿，只有两条被验证的路：
  • 甲 · 门派网络（waytoAGI 式）：切磋大会做成品牌活动，认证讲师/城市分舵 500 个 × 年贡献 20 万 = 1 亿
  • 乙 · B 端方案（零犀式）：AI 办公提效做成政企标准化改造 + 效果付费
  • 分舵 = "被看见 + 被承认 + 一起走"的线下实体化，复制的是"门派系统"而非某个人。
  • 当前姿势：先把中原第一做扎实，哪条腿长出来走哪条——本蓝图是甲腿的施工图。

二、分舵单元模型

1 分舵 = 1 分舵长(认证讲师 Lv2+) + N 本地助教
        + 本地渠道(1 夜校 / 1 高校 / 1 政企)
        + 本地社群(研习社城市版)
维度 统一（总部控） 自主（分舵长控）
品牌 视觉/话术/认证标准 本地活动命名
内容 知识库 / 实战营课程 / 作业飞轮 本地案例补充
经营 质量品控 本地招生 / 本地 B 端拓展 / 本地活动

三、分舵长选拔（从认证体系晋升）

  • 路径：认证学员(Lv1) → 认证讲师(Lv2，接单分销) → 分舵长（运营 1 分舵）
  • 门槛：带过 ≥2 期实战营 + 握本地资源（场地/渠道/人脉） + 皇上面试授牌
  • 权益：分舵品牌使用权 + 本地收益分成 + 总部内容/系统/认证支持

分舵长不是"加盟商"，是门派体系的本地算子——先证明能跑通本地飞轮，再给牌子。

四、分润与权责

  • 分润：分舵本地收入（实战营 / 内训 / 研习社城市版）按 总部 X% + 分舵长 Y% 分账（具体比例皇上定，建议总部 20–30% 含系统支持）
  • 权责：用统一品牌须过质量品控（作业飞轮 / 认证标准不变）；擅自改定位、乱承诺 = 摘牌
  • 飞轮：分舵产出本地案例 → 回流总部知识库/案例库 → 总部赋能分舵 → 分舵更强（双向）

六、单分舵经济模型（对标 v3 测算）

  • 参考收入：研习社城市版 300 人×365 + 实战营 4 期×30×2999 + 2 内训×2 万 ≈ 年 80–120 万
  • 总部抽成 20% ≈ 年 16–24 万/分舵；500 分舵 ≈ 1 亿/年（v3 甲腿目标）

七、风控（门派生意的命门）

  • ❌ 品牌不一致（统一视觉/话术/认证，违者摘牌）
  • ❌ 质量失控（作业飞轮/认证标准总部控，分舵不得擅自放水）
  • ❌ 信誉红线（不包赚钱/不天价）分舵同守——一处翻车全门派陪葬
  • ✅ 退出机制：连续 2 季不达标 → 降级 / 摘牌，保护品牌
