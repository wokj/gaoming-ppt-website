3.3 可复用打法（累计六条，W43 新增第 5、6 条）

  1. 「官方原文 + 被点名」结构——权威感的最短路径（沿用 W38）。 转述官方原文 → 给"能做/不能做"判断树。同行无法反驳；天然形成收藏动机。

  2. 「具体数字的清单体」——收藏率的直接来源（沿用 W39）。 清单进首图，判断进正文。高潜力选题几乎全部带具体数字（254 单 / 700 元 / 5000 个项目 / 10/23-25-30-31 / 7 天课表）。

  3. 「公域内容 = 私域资产的公开切片」——内容与产品是同一件东西（沿用 W41）。 不写"介绍某张表的文章"，而是把那张表直接摊开。生产成本降、天然不可复制、发出去的同时就在卖产品。

  4. 「机制级 > 扣分级」的选词法（沿用 W41）。 标题与首图只写"不予进入评审 / 取消资格 / 上传失败"，不写"可能扣分 / 会被怀疑"。

  5. 【W43 新增】「自有数据 = 不可复制的护城河」——从"讲方法"升级为"出示证据"。 W42→W43 最重要的一个转变：过去所有选题都在讲"应该怎么做"，254 单篇第一次开始讲"我这么做成了"。 - 为什么强：同行能抄你的观点、抄你的结构、抄你的金句，唯独抄不了你的订单表； - 为什么此刻可行：AI 已把"做 PPT"打到 50 元/套，所有人对"方法"都已免疫，只对"结果"还有反应； - 落地动作（可直接复用的公式）：一个可核验的自有数字 + 一条翻车过的曲线 + 一条"我砍掉了什么"的负面清单。三条齐备，内容即无法被复制。 - 可延展的资产：订单表里还有大量未开采的数据——复购客户占比、返工轮次分布、客户来源分布（朋友圈 100%）、不同品类的页均单价。每一次开采都是一条独家选题，且这个机会是同行永远没有的。

  6. 【W43 新增】「四校样本对照法」——用"同一件事的不同叫法"证明一个缺口。 10-12/10-14 集训营选题的论证方式值得固化为模板：找 4 个同类主体 → 列出各自对同一件事的表述 → 指出"没有一家写到的那一项"。 - 为什么强：单个案例是"例子"，四个案例是"证据"；且它天然带有"我们做了你没做"的位差，是最不像广告的广告； - 落地动作：B 端内容（高校/机构）优先用此法；C 端内容（学生/教师）则改用"三省口径对照"（同一比赛在不同省份的不同执行）。
