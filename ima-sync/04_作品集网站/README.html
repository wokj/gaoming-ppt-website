高明之选 PPT 作品集网站

对标同行「建委JIANWEI」（jianwei.appmiaoda.com）开发的高明之选 PPT 作品集官网。 纯静态多页站点：零依赖、零后端、离线可用，可部署到任意静态托管。

一、需求分析（对标结论）

竞品模块 本站对应实现 本站增强
首页·最新作品流 index.html：Hero + 数据背书 + 精选作品 + 三级服务体系 + 流程 + 优势 增加明码报价、双IP背书
/cases 案例列表 cases.html：5 大分类筛选 + 卡片流 卡片为纯 CSS「迷你幻灯片」，永不裂图
/cases/:id 详情 case.html?id=xxx：背景/方案/交付清单 + 相关推荐 增加交付物明细与同类推荐
/cooperation 表单 cooperation.html：三级报价 + FAQ + 意向表单 表单无后端 → 生成摘要一键复制发微信

二、技术架构

04_作品集网站/
├── index.html          # 首页
├── cases.html          # 作品案例列表（分类筛选）
├── case.html           # 案例详情（?id= 参数客户端渲染）
├── cooperation.html    # 合作咨询（报价/表单/FAQ）
├── assets/
│   ├── css/style.css   # 全局样式（墨黑×描金视觉系统）
│   └── js/
│       ├── data.js     # ★ 单一数据源：站点配置 + 21个案例 + 三级服务
│       └── main.js     # 渲染/筛选/详情路由/动效/表单
└── README.md           # 本文档
  • 数据驱动：所有案例内容集中在 data.js，增删案例只改这一个文件
  • 无外部依赖：字体走系统字体栈，无 CDN、无框架、无外部图片（卡片预览为 CSS 手绘）
  • 响应式：桌面 / 平板 / 手机三档断点，移动端汉堡菜单
  • 动效：IntersectionObserver 入场动画，尊重 prefers-reduced-motion
  • 安全：所有数据输出经 esc() 转义，防 XSS

三、日常维护指南

1. 新增/修改案例

编辑 assets/js/data.js 的 CASES 数组，复制一条现有记录改字段即可：

{
  id: "english-id-unique",        // 唯一英文 id（详情页链接用）
  title: "作品标题",
  cat: "bp",                       // bp=商业计划书 race=创赛路演 train=培训课件 brand=品牌与定制 insight=行业洞察
  featured: true,                  // 是否精选（首页展示前6个精选）
  year: 2026, pages: 30, duration: "8 个工作日",
  client: "客户类型", scene: "应用场景",
  tags: ["标签1", "标签2"],
  summary: "项目背景一段话",
  design: "设计方案一段话",
  deliverables: ["交付物1", "交付物2"]
}

2. 配置联系方式（上线前必做）

编辑 data.js 顶部 SITE.contact，填写 wechat / phone / email， 合作页右侧联系卡片自动展示；留空则显示配置提示。

3. 调整价格/服务内容

  • 首页与合作页的价格卡片是 HTML 直排（两处），修改对应 <section> 中 .tier 区块
  • 合作类型下拉选项在 cooperation.html 的 <select id="f-type">

四、本地预览

cd 04_作品集网站
python -m http.server 8642
# 浏览器打开 http://127.0.0.1:8642

（直接双击 index.html 也能看，但案例详情页的 ?id= 参数在 file:// 协议下部分浏览器受限，建议用本地服务器）

五、部署上线

本站为纯静态站点，任选其一：

方式 说明
WorkBuddy「发布为应用」 对话中说"把这个网站发布上线"即可，生成在线分享链接
腾讯云 COS / 阿里云 OSS 静态托管 上传整个目录，开启静态网站功能
GitHub Pages / Vercel 免费方案，适合海外访问
自有服务器 任意 Web 服务器（Nginx/Apache）指向本目录即可

注意：绑定自有域名部署在中国大陆境内需 ICP 备案；用 WorkBuddy 发布或境外托管则无需。

六、已知限制与二期建议

  • 表单无后端：当前为「生成意向摘要 + 复制发微信」方案；二期可接入表单服务（如腾讯问卷/金数据嵌入）或云开发函数
  • 案例缩略图为 CSS 手绘示意：二期可将真实 PPT 首页导出为 PNG 放入 assets/img/，在 data.js 中加 cover 字段替换
  • 浏览量/点赞数为竞品功能，本站以「页数/周期/交付物」等 B2B 更可信的元数据替代
